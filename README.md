# 磁弘科技 (东莞) 有限公司企业官网

## 项目简介
本项目是磁弘科技 (东莞) 有限公司的企业官网，包含首页、关于我们、产品中心、解决方案、客户案例和联系方式等模块，兼具科技感与专业性。

## 项目结构
- `index.html`：网站主页文件。
- `styles.css`：网站样式文件。
- `script.js`：网站交互逻辑文件。
- `requirements.txt`：项目依赖文件。

## 功能模块
1. **首页**：品牌视觉呈现，核心定位标语，价值主张突出，包含行动按钮。
2. **关于我们**：企业简介、使命与愿景、核心价值观。
3. **产品中心**：分类展示产品，支持按应用领域和技术参数筛选。
4. **解决方案**：行业应用场景和技术优势说明。
5. **客户案例**：展示标杆合作案例。
6. **联系方式**：基础信息和即时沟通功能。

## 设计要求
- 主色调：科技蓝 + 工业灰，搭配新能源领域的绿色元素。
- 动态效果：产品 3D 展示、参数悬浮提示。
- 转化引导：产品页底部设置咨询表单，首页轮播图添加下载按钮。

## 运行方式
直接在浏览器中打开 `index.html` 文件即可查看网站。
